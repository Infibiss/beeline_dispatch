# Настройка бригад до начала дня

Пользователь разрешил первый следующий этап: состав, домашние старты, утренний запас, интерфейс; README сократить. Реализация в текущей ветке с отдельными коммитами.

- Отдельная страница /crew из шапки диспетчера; без четвертой ежедневной вкладки.
- CRUD бригад: имя, смена, навыки, транспорт, известная стартовая точка или подтвержденный результат поиска нового адреса. Старт — модель дома, не GPS.
- Выдача: под рассчитанный план + указанный резерв либо фиксированный запас с жестким ограничением назначения. Для дома выдача предполагается завершенной до начала смены, допущение видно в UI.
- Только до первого операционного события/факта. Предпросмотр отдельно от применения; версии и атомарная запись защищают от устаревшего плана и сбоя диска. История прежних планов сохраняется.
- Контрольное число бригад: Восток 12, Юго-восток 12, Югоцентр 11; только агрегаты, исходные назначения не передаются оптимизатору.
- Тесты: запас/резерв, навыки, домашние точки, начало смены, версии, запрет после фактов, атомарное API-применение. Проверка UI и сборки, коммит.
