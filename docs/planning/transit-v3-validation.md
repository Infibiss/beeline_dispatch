# Комбинированный транспорт v3

## Фактическое покрытие
Рельсовая сеть: 20 линий, 440 записей станция/линия. Метро, МЦК, D1-D4; географический справочник HH с исправленной топологией. Снимок для даты исходных заявок 17.08.2026: Рублёво-Архангельская открылась позже и не включена. Не все новые остановки МЦД присутствуют; Левобережная пока консервативно исключена в обоих направлениях из-за опубликованного ограничения одного направления.

Наземная сеть: скачан GTFS-архив MobilityDatabase mdb-3226 от 30.06.2026. Исходно 877 маршрутов, 17 896 остановок, 224 851 поездка. На понедельник 17.08.2026 активно 65 475 поездок с валидными прочитанными временами; скомпилированы 323 частых автобусных/трамвайных маршрута, из них 307 имеют доступную посадку после окончательной проверки работы с 09:00 до 22:00. Каждое направление, точная последовательность и повторное посещение остановки отделены. Неактивные, редкие и ограниченные временем работы маршруты не объявляются доступными весь день.

## Расчёт
Граф содержит рельсовые станции, уличные остановки и позиции внутри маршрутов. Вход в автобус/трамвай оплачивает ожидание один раз; пересадка на другой маршрут требует нового ожидания. Явные направленные рёбра исключают ложные связи развилок и обратное движение против направления маршрута.

Наземное время сегмента — максимальное наблюдаемое время из расписания; ожидание — полный максимальный интервал, пересекающий рабочий день 09:00–22:00. Посадка разрешена только при наличии отправлений не позже 09:00 и не раньше 22:00. Первичный фильтр частых маршрутов: >=12 отправлений в дневном диапазоне, начало до 10:00, конец после 21:00, половина P90 интервала <=20 мин. Это консервативная постоянная оценка по опубликованному расписанию, не гарантия реального времени и не поиск по конкретному отправлению.

Для каждой точки рассматриваются 6 рельсовых станций до 2.5 км и 3 уличных остановки до 800 м. Пешие подходы/выходы направленные, по OSRM; плохие привязки >150 м и недоступные пути отбрасываются. Пересадки между станциями и уличными остановками ищутся до 700 м, затем проверяются foot-сервисом. Между автобусными маршрутами есть пересадки на одной физической остановке; соседние разные автобусные остановки пока не соединяются автоматически.

Вне известной сети v3 не выдумывает поездку на среднем общественном транспорте: остаётся дорожная пешая альтернатива. Это может снизить назначения на удалённых участках без покрытой железной дороги.

## Ограничения точности
Нет реального времени, текущих пробок и полной базы закрытий. Рельсовое время — расстояние/35 км/ч + минута на остановку; ожидание 3 мин для метро/МЦК, 6 для МЦД. Входы до конкретного турникета не подтверждены. Расстояния автобусов между остановками прямые: shapes.txt в архиве отсутствует. Полнота сети и фактическая ошибка времени по независимому набору поездок не доказаны.

Файлы источников и команды пересборки: src/field_router/data/METRO-SOURCE.txt и SURFACE-SOURCE.txt. Архивы не включены в пакет, SHA256 зафиксированы. Проверка источника сама по себе не означает актуальность всех поездок на 20.09.2026.

## Проверки
Регрессии: направленная развилка без ложного соединения по order, однократное ожидание при непрерывной поездке, раздельные повторные остановки кольцевого маршрута, сохранение реального порядка Некрасовской/Филёвской, отсутствие выдуманного среднего транспорта вне сети. Сохранённые планы проверяются независимым валидатором и тестами рабочего дня.

Пешеходный кэш при финальной замене только весов расписания перенесён после строгой проверки совпадения всех физических узлов (включая координаты). Подпись графа обновлена явно; обычная загрузка по-прежнему отвергает несовпадающую подпись.

## Результат проверки 20.09.2026
Полный scripts/check.sh: 214 тестов, сборка wheel и проверка обязательных ресурсов. Тесты включают рабочий день, оборудование, отмены, сохранение начатых работ и независимую проверку всех сохранённых планов. Регрессии транспортного графа проверяют также конец обслуживания и полный интервал ожидания; ИИ — допустимый выбор, единый формат JSON, преимущества/компромиссы и совпадение показателей.

Финальные демо с тем же пулом из 15 бригад, OR-Tools с лимитом 5 секунд: Восток 66/66, Юго-восток 71/83, Югоцентр 55/56. Это допустимые решения, не доказанные оптимумы. Дорожные линии пересчитанных авто/пеших/веломаршрутов обновлены через OSRM. Проверка живой YandexGPT выполняется отдельно от CI; платный API в автотестах заменён контролируемым ответом.
