# Обновление UI диспетчера — 18.09.2026

Запрос: простой, лаконичный интерфейс в палитре Билайна. Применены желтый акцент, черный текст и белые/светло-серые поверхности. Три вкладки: План дня, Перепланирование, Статусы инженеров.

Повторные заголовки и вводные абзацы убраны. Ограничения доступны в «О данных», география кратко помечена на плане. Объяснения вариантов, ведомость оборудования и история закрепленных работ раскрываются по запросу. Изменения и утверждение показываются после выбора варианта. Ошибки, конфликт версий и необходимость пересчета остаются видимыми. Встроенный план прокручивается вместе со страницей.

Состояние, маршруты и правила планирования не менялись. Палитра в стиле бренда; CSS-знак не является импортированным официальным логотипом.
