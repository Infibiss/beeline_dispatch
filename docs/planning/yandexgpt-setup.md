# Подключение YandexGPT Lite — что подготовить

Проверено по документации 20.09.2026. LLM подключена: общая плашка над тремя карточками: «Выбрать с помощью ИИ». Сервер автоматически читает перечисленные настройки из .env; переменные процесса имеют приоритет.

1. Каталог Yandex Cloud/AI Studio с доступным биллингом, его folder ID.
2. Сервисный аккаунт с ролью `ai.languageModels.user` и API-ключ для Responses API с областью `yc.ai.foundationModels.execute`.
3. Сохранить локально, например в игнорируемом `.env`: `YANDEX_FOLDER_ID`, `YANDEX_API_KEY`. Не присылать ключ в переписке, не коммитить.
4. Выбранная модель: `gpt://<folder_id>/yandexgpt-5-lite` по актуальному каталогу моделей. Endpoint Responses API: `https://ai.api.cloud.yandex.net/v1/responses`.
5. На старте ограничить выход 500 токенами, кэшировать объяснение по версии плана/кандидату. Отправлять только обезличенные рассчитанные показатели/причины, без адресов и координат. Модель не меняет назначения и не утверждает план. При сбое остаётся детерминированное объяснение.

Тариф YandexGPT Lite на момент проверки: 0.20 ₽ / 1000 входящих и 0.20 ₽ / 1000 исходящих токенов, с НДС. 2000 входящих + 500 исходящих ≈ 0.50 ₽ за объяснение без дополнительных услуг. По умолчанию YANDEX_LLM_MAX_CALLS=20 за запуск процесса; это ограничение количества вызовов, не бухгалтерский лимит рублей. Повторные запросы одного варианта/пакета кэшируются в памяти; сбои тоже, автоматических повторов нет.

Пользователь настроил ключ и каталог. Проверочный вызов API выполнен успешно. Значения секретов не выводились и не включены в репозиторий. Объяснение справочное: модель не меняет подписанные предложения или назначения. Таймаут 25 секунд, сбой/пустой/незавершённый ответ заменяется обычным пояснением. Работа сервера с планом не блокируется сетевым ожиданием LLM.

LLM выбирает candidate_id и 2–4 идентификатора проверенных тезисов; вариант сверяется с пакетами, приоритетами и доминированием; свободный текст от модели не отображается. Показатели и сравнения выводятся кодом из рассчитанных вариантов. Это ограничение введено после того, как Lite в живой проверке перепутала показатели стратегий. Невалидный формат ответа заменяется базовым пояснением.
