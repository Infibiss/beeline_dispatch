# Поздние факты, исправления и новый адрес

## Факты

1. Откройте «Статусы инженеров», оставьте «Новый факт», выберите инженера и статус.
2. Если сообщение пришло позже события, включите «Сообщение пришло с задержкой». Укажите время самого события, например 12:45, даже если сейчас в сценарии 12:50. В списке будут доступны исторические назначения выбранного инженера.
3. Для работы укажите остаток минут. Для завершения пустой расход означает оставшуюся потребность заявки; для прерывания укажите остаток и фактический расход явно, включая нули.
4. Нажмите «Записать факт». Текущие часы не откатятся; в журнале отдельно появится время записи сообщения.
5. Нажмите «Перейти к пересчёту» → «Рассчитать варианты», сравните результат и примените выбранный план. Запись факта сама по себе не публикует новый маршрут.

Для исправления выберите существующую запись в поле «Запись», измените данные и укажите причину. Предыдущая версия остается в «Истории исправлений». Если исправление противоречит более поздним фактам, оно отклоняется целиком: проверьте последовательность, расход и принадлежность заявки. Инженера существующей записи менять нельзя. Для одного инженера несколько фактов в одну минуту пока не поддерживаются.

## Режим учета

«Демо: по плану, если нет фактов» моделирует работу инженеров, для которых еще нет ручных сообщений. После первого факта инженер требует дальнейших сообщений: статус «Работает» не превращается в завершение по часам.

«Ручной: только факты» не назначает новые заявки инженерам без фактического статуса. Сначала внесите их доступность и местоположение. После переключения режима пересчитайте и утвердите план. Режим не удаляет предыдущие факты и версии.

## Новый адрес

Доступен только в дорожной сессии с включенными сетевыми запросами. Основной интерфейс localhost:8766 теперь использует дорожную сессию; поиск включен. В старой синтетической сессии он недоступен.

В «Перепланировании» выберите «Аварийная заявка», раскройте новый адрес, введите город, улицу и дом, нажмите поиск. Выберите кандидата и проверьте точку на карте. Подтверждение сохраняет адрес только после успешного получения дорожных матриц. Затем задайте время, длительность и оборудование аварии и рассчитайте варианты обычным способом.

Приближенный результат явно помечается, исходный адрес сохраняется. Ошибка сети не добавляет половину матрицы и не меняет план. Устаревший выбор требует повторного поиска. При добавлении точки действующие предложения планов сбрасываются: их нужно пересчитать. Подтверждение точки само по себе не создает и не назначает аварию.

Для поиска адрес передается Photon; для расчета дорог координаты передаются OSRM. Пользователь разрешил эти запросы. Живой сквозной тест пройден на адресе «Москва, Тверская улица, 7»; для остальных вводимых адресов доступность проверяется при подтверждении.
