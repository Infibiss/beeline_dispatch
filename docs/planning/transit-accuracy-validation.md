## Рабочий день

Автотест ручного дня: начало смены → поездка → работа → задержка → отмена другой заявки → авария → прерывание с частичным расходом оборудования → перепланирование → завершение → сохранение/восстановление → закрытие оставшихся работ → конец смены. После каждого утверждения проверяется баланс оборудования.

Три сохранённых дорожных участка дополнительно прошли симуляцию: утро, авария в 11:50, отмена доступной будущей заявки, дневной пересчёт, восстановление состояния, конец смены. Проверяется отсутствие потери/дублирования заявок между историей, отменами и остатком. Это автоматическая симуляция, не полевой тест.
