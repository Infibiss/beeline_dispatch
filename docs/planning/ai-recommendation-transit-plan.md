# Рекомендация ИИ и покрытие транспорта Москвы
Пользователь задал место плашки и действие: общая рекомендация перед тремя карточками, кнопка «Выбрать с помощью ИИ», вариант и причины, без автоматического утверждения.
LLM возвращает candidate_id и проверенные тезисы. Проверка существования варианта, приоритетов аварий/подключений; отклонение строго доминируемого решения. При ошибке честная рекомендация по правилу с подписью, не «ответ ИИ». Кэш по пакету; сброс при изменении события, защита от запоздалого ответа.
Транспорт: проверить свежие источники (OSM, GTFS, справочники); учитывать топологию и направления, входы/выходы по дорогам, расписания только при подтверждённых датах. Не выдавать недействующий архив за актуальное расписание. Тесты и проверка конкретных маршрутов, обновление демо и отчёт о фактическом покрытии.
