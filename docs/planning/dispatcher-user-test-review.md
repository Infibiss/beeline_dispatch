## Исправления

- В пользовательских элементах диспетчера аварии имеют названия «Авария №N»; внутренние уникальные ID сохранены.
- Список фактических заявок содержит исполнителя, фильтруется при выборе инженера; фактически завершенные исключены.
- Для работающего инженера доступны обновление остатка, завершение и прерывание его текущей работы. Сервер также запрещает смену работы без явного завершения/прерывания.
- Неотносящиеся к статусу поля заявки и остатка очищаются на сервере; «свободен» не несет старую заявку.
- Показаны последний факт и допустимое время следующего. Учет последовательный: факт нельзя записать раньше глобального времени состояния; новый факт одного инженера должен быть позже предыдущего. Редактирование истории задним числом не реализовано.
- Запись факта не запускает расчет. Есть явная кнопка «Перейти к пересчету», выбран тип «Пересчитать по фактам», показан следующий шаг. После расчета инструкция сменяется сравнением; утверждение по-прежнему отдельное.
- Обычная ошибка ввода HTTP 400 не блокирует всю форму; конфликт версии/сбой соединения требует обновить состояние.
- Таблица сравнения: охват приоритетных, неназначенные, потерянные назначения, начало новой аварии, смены инженера, сдвиги, дорога и ресурсы. Сортировка меняет только порядок просмотра, не цель solver и не утверждает план.
- Показаны конкретные причины неназначения и список изменений. Явная отмена заявки не считается непреднамеренной потерей назначения.
- Предупреждение о ручных фактах старше времени события. Последующее выполнение не считается подтвержденным автоматически.
