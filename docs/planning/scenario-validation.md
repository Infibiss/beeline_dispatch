## Границы результата

- Это симуляция по расписанию и условным точкам, не дорожная/GPS-система. Результаты по реальной географии еще ждут уточнения адресов.
- Метрики карточек относятся к пересчитываемому остатку, исключают закрепленные работы/их дорогу. Таблица показывает их отдельно.
- SLA-first означает раннее начало приоритетных работ при общем приоритете охвата; договорный SLA/рублевые ставки не определены.
- LLM не подключена: пакет фактов подготовлен, объяснение пока шаблонное. Провайдер и передача ему данных не настроены.
- Нет частичного расхода устройств, прерывания начатой работы, передачи устройств между инженерами, локального/кластерного расширения поиска. Сейчас OR-Tools пересчитывает доступный остаток участка.
- Первая демонстрация использует существующий адрес для координат новой аварии; произвольный новый адрес требует отдельной географии.
