# Scenario Engine — план реализации

Согласованный результат: событие → три допустимых варианта SLA-first / Stable / Cost-first → сравнение изменений → явное утверждение диспетчером. LLM объясняет рассчитанные факты, не принимает решения и не проверяет допустимость.

Архитектура первой поставки: локальный сервер и отдельная страница Scenario Center; существующие Scenario/Plan/валидатор. Демонстрация событий на явно синтетической географии, без GPS и без подмены ее реальными дорогами. Время события вводит диспетчер; состояние симулируется по утвержденному плану и подписывается как симуляция. Дорога в симуляции линейно интерполируется между условными точками; это не дорожный GPS. Выполненное не меняется. Для начатой работы режим должен явно сохранять ее до завершения; согласование правила запрошено. Перенаправление в пути — переключатель диспетчера при аварии. Устройства списываются по завершении, резерв текущей работы недоступен другим работам.

Общие цели вариантов: сначала охват высшего уровня, затем общий охват. SLA-first дополнительно предпочитает раннее начало приоритетных работ (это показатель отклика, не договорный SLA); Stable — сохранение инженера и времени; Cost-first — инженеры/километры. Все временные окна и смены жесткие. Деньги не выдумываются. Совпавшие варианты явно отмечаются; различия не создаются искусственно.
