# Источники географии и правила запуска

Состояние на 18.09.2026. Выбор провайдеров заменяемый, URL передаются CLI. Подключение само по себе не доказывает качество геокодирования.

## Адреса

[Photon](https://github.com/komoot/photon) — геокодер данных OpenStreetMap. Публичный сервер допускает умеренное использование, может ограничить запросы и не гарантирует доступность. В реализации один последовательный клиент с интервалом не менее 1.1 секунды и дисковым кэшем всех успешных ответов, включая пустые. Нет автодополнения адресов и фонового регулярного геокодирования. Сеть включается только флагом `--network`.

Передаются только адреса заявок/офисов. После первоначального запроса пользователь разрешил Photon и поручил продолжить подключение географии. Используются только синтетические наборы. Решение о передаче данных не распространяется на контрольные файлы или сведения инженеров.

Автоматически принимается один уникальный кандидат с полным совпадением нормализованных города, улицы и номера дома с корпусом/строением. Область проверки: 36.5–39° долготы, 54.8–56.6° широты. Это фильтр явно чужих результатов, а не гарантия кадастровой точности. Сохраняются исходный адрес, поисковый запрос, OSM ID, координаты и качество. Неоднозначные/отсутствующие совпадения записываются в `unresolved`; расчет на таком наборе запрещен.

Ручное исправление — JSON по ID точки с `lat`, `lon`, `quality: "manual"`, непустым `source` и необязательным `label`. Офис имеет ID `office`. Не отмечать ручную проверку без фактического источника. После изменения координат матрицы надо перестроить; подпись координат блокирует старые матрицы.

Публичный Nominatim не используется. Его [политика](https://operations.osmfoundation.org/policies/nominatim/) содержит дополнительные ограничения на использование через платформы генерации приложений.

## Поездки

[OSRM/FOSSGIS](https://routing.openstreetmap.de/about.html): максимум один запрос в секунду, атрибуция, без тяжелого использования. Используются кэш и пауза 1.1 с. Демо ограничено 100 точками на матрицу. При масштабировании — собственный экземпляр или коммерческий провайдер.

Профили из публичной конфигурации сервиса: `routed-car` / `driving`, `routed-foot` / `foot`, `routed-bike` / `bike`. Расстояния матрицы — длины выбранных быстрых маршрутов, не прямые расстояния и не обязательно кратчайшие пути. Время возвращается в секундах, округляется вверх до минут. Направления могут отличаться. Null/ошибки/привязка дальше 500 м блокируют подготовку; скрытого перехода на синтетику нет. [API](https://project-osrm.org/docs/v5.24.0/api/).

Общественный транспорт: только по явному `--allow-public-estimate`, оценка от автомобильной дорожной длины / 18 км/ч + 7 минут для ненулевого участка. Это не расписание, не схема метро и не реальный маршрут транспорта. Пешеходные подходы, пересадки и зависимость от времени не моделируются. На карте показывается пунктирная последовательность визитов, а не выдуманная линия автобуса.

OSRM не предоставляет актуальные пробки и не прогнозирует движение на дату визита. Дата графа сохраняется, когда сервер ее возвращает. Все поездки — модельные.

## Карта и лицензии

Leaflet 1.9.4 хранится локально вместе с лицензией BSD-2-Clause; JS/CSS SHA-256 сверены с [официальной страницей](https://leafletjs.com/download.html). Открытие рабочего места не требует скачивания кода из CDN.

Подложка OpenStreetMap — только видимая область, без предзагрузки/скрейпинга, с атрибуцией и ссылкой исправления карты; действует [политика тайлов](https://operations.osmfoundation.org/policies/tiles/). При недоступности подложки точки, линии и расписание остаются доступными. Данные © OpenStreetMap contributors, ODbL; не удалять атрибуцию при распространении результатов.

Практическая проверка Photon: структурированный endpoint вернул `search_phase_execution_exception`; используется обычный поиск с полным написанием «корпус»/«строение». При точном адресе здание предпочитается организации внутри него только если здание одно, а остальные совпавшие объекты не дальше 100 м. Два здания или удаленные совпадения остаются неоднозначными.
