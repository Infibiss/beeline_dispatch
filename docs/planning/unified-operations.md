# Единое рабочее место, география и фактические статусы

Пользователь поручил выполнить пункты 1–3, затем проверить вместе. ML/GPS/LLM-функции пункта 5 и ALNS в этот этап не входят.

- [x] Единый локальный интерфейс: вкладки текущего плана и событий, карта/расписание после утверждения берут свежую версию с сервера. История версий доступна для просмотра. Первоначальный статический dispatcher остается экспортом, не источником актуального состояния.
- [ ] Реальная география: проверить оставшиеся адреса в независимых источниках, сохранить источники и координаты точных совпадений. Неразрешенные корпус/строение не заменять без подтверждения. Пересчитать доступные полные наборы по дорожным матрицам; явно отчитаться о блокирующих адресах.
- [x] Фактические статусы: ручное сообщение диспетчера о состоянии вместо молчаливого исполнения расписания. Сохранение фактов как отдельной версии; начало/завершение, время, позиция и расход устройств проверяются. Незавершенную работу не считать законченной по часам. Для прерывания факты о потраченном оборудовании и остатке работы вводятся явно; не придумывать расход. Симуляция остается отдельным режимом.
- [x] Сквозная проверка и документация, без подключения внешнего LLM или ALNS.

География выполнена частично: 24 дополнительных точных совпадения, 197/208. Полные дорожные расчеты заблокированы 11 неоднозначными точками; список в address-resolution-2.md. Никакие неподтвержденные адреса не подставлены.
