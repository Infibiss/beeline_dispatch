# Приложение инженера и GPS

1. Запустите сервер по README и войдите как диспетчер. В «Доступ сотрудников» выберите регион, инженера, логин и пароль (12–128 символов). Инженер получает доступ только к своему региону и своим заявкам.
2. На телефоне откройте адрес сервера `/engineer`, войдите под созданным логином. «Заявки» — работы и маршрут; «Смена» — старт, оборудование и добровольная передача GPS. Открывайте заявку для записи выезда, начала и сообщения о выполнении. Время — часы рабочего дня сценария; для одного инженера сообщения должны иметь разные минуты.
3. Сообщение о выполнении освобождает инженера, но окончательное закрытие подтверждает диспетчер во вкладке «Статусы инженеров». До подтверждения заявленный расход недоступен для новых работ. Если время или расход неверны, диспетчер уточняет запись с причиной. Пересчёт маршрута и его утверждение выполняются отдельно.
4. GPS запускается отдельной кнопкой и запросом браузера на доступ к местоположению. «Остановить» и выход из аккаунта прекращают передачу. На HTTP localhost можно тестировать с компьютера; с телефона нужен доверенный HTTPS. Страница должна оставаться открытой: фоновые обновления на заблокированном телефоне не гарантируются.

## Локальный HTTPS

На машине с OpenSSL:

```sh
.venv/bin/python -m field_router.local_https --directory output/local/https --ip 192.168.1.10
.venv/bin/python -m field_router.scenario_server data/demo-road/Восток.json --state output/local/east-state.json --regions-dir data/demo-road --host 0.0.0.0 --port 8766 --certfile output/local/https/server.crt --keyfile output/local/https/server.key
```

Замените IP на адрес компьютера в одной сети с телефоном. Команда создаёт CA и серверный сертификат, но не меняет системное доверие. Для тестового телефона установите и явно разрешите доверие **только публичному** `local-ca.crt` в настройках сертификатов ОС. Откройте `https://<IP>:8766/engineer`; браузер не должен показывать ошибку сертификата. Файлы `.key` остаются на компьютере. После проверки удалите доверие тестовому CA; для размещения используйте обычный доверенный сертификат. В Windows есть `scripts/create-local-https.ps1` и `scripts/start-local.ps1`.

## Что означает GPS на экране диспетчера

- Канал «Устройства» — принятые координаты; «Демо» — отдельные тестовые события и импорт CSV/JSON-трека. Пример трека доступен прямо в панели. Демо не записывает факты и не меняет план.
- Фильтр Калмана сглаживает координаты. Правила отмечают остановку, удаление от адреса, близость к объекту, несвежую точку и риск окна. Это сигналы для проверки, не доказательства простоя или нарушения.
- GPS ETA — диапазон по расстоянию по прямой с поправками на транспорт, без дорожного запроса и пробок. Комбинированные матрицы используются **в оптимизаторе**, пока не в этом GPS ETA.
- Сигналы зависят от даты сценария. Для августовского демо в другой календарный день используйте тестовый канал, иначе сравнение с часами маршрута не выдаёт оперативные предупреждения.
- Буфер координат ограничен и хранится в памяти; перезапуск очищает его. Долгий расчёт маршрута не блокирует авторизованный приём координат. Недоступность GPS/аналитики не закрывает заявки и не утверждает план.

## Доступ и сохранения

Пароли хешируются, сессии отзываются при блокировке аккаунта или смене пароля. Удаление инженера из состава закрывает ему доступ к данным/телеметрии региона. План и журнал лежат в JSON, аккаунты — в SQLite. Не публикуйте эти файлы или `.env`. После перезапуска нужен новый вход; рабочий день и учётные записи сохраняются.
