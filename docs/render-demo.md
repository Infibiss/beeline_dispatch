# Демо на Render Free

Один Docker Web Service, один экземпляр, без постоянного диска и отдельной базы.
Все вошедшие пользователи работают с одним общим днём в каждом из трёх регионов.
Каждый запуск процесса восстанавливает исходные сценарии; применённые планы,
факты, дополнительные аккаунты и GPS-история при перезапуске пропадают.
Выгрузите нужные результаты до обновления. Локальные состояния в образ не входят.

## Образ

Собирать из корня для Render (linux/amd64):

```sh
docker build --platform linux/amd64 -t field-router-demo .
```

Образ запускается непривилегированным пользователем. Включены три исходных
региона, карта и транспортная модель. Бюджеты: утро 10 секунд, день 3 секунды
на вариант. GPS включён; производительность и память проверяются на Render.
Docker Hub / другое выбранное registry должно хранить образ приватно.

## Render

New → Web Service → Existing Image. Выбрать опубликованный образ и Free.
Health Check Path: `/healthz`. Docker Command оставить пустым.
Внешний HTTPS URL автоматически берётся из `RENDER_EXTERNAL_URL`.
Для собственного домена задать `FIELD_ROUTER_PUBLIC_ORIGIN=https://ваш-домен`.
Произвольные `X-Forwarded-*` не используются для разрешения запросов.

Секреты окружения:

- `FIELD_ROUTER_ADMIN_PASSWORD`: отдельный пароль демо, 12–128 символов. Логин `admin`.
- `YANDEX_API_KEY`, `YANDEX_FOLDER_ID`: существующие настройки LLM.
- `YANDEX_MODEL`: выбранная модель (необязательно).
- `YANDEX_LLM_MAX_CALLS=20`: лимит вызовов на процесс, сбрасывается при перезапуске.

Не помещать `.env`, пароли, ключи registry или deploy hook в образ и Git.
Пароль администратора публичного сервера не печатается в журнал.
Перезапуск сервиса возвращает и начальный пароль из окружения.

## Проверка после размещения

1. `/healthz` отвечает 200 без выдачи данных; `/api/state` без входа отвечает 401.
2. Войти, открыть каждый регион, рассчитать три варианта события и применить один.
3. Проверить запись факта, страницу инженера и объяснение LLM.
4. Перезапустить сервис и убедиться, что восстановился исходный день.
5. Проверить память и время расчётов на бесплатном сервере.

Free засыпает после 15 минут без обращений; холодный старт может занять около
минуты. Это стенд для оценки, не постоянное рабочее хранилище.

## Автоматическое обновление

SourceCraft остаётся основным репозиторием. После успешных проверок main CI
должен собрать linux/amd64-образ с тегом SHA коммита, отправить в приватное
registry и вызвать Render deploy hook с этим тегом. Доступ CI на запись и
доступ Render только на чтение задаются отдельно. Публикацию из pull request
не включать. Конкретные адреса и секреты задаются после подключения registry.

Подготовлен `scripts/deploy_render.py`: он собирает образ с полным SHA коммита,
отправляет его в `docker.io/infibiss/field-router-demo` и только после успешной
отправки вызывает Render. Для него нужны секреты `DOCKERHUB_PUSH_TOKEN`
(отдельный токен Read & Write без Delete) и `RENDER_DEPLOY_HOOK`.
Скрипт пока не включён в CI: hook будет доступен после создания сервиса.
