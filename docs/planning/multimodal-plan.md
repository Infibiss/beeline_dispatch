# Комбинированное перемещение — план и границы

Пользователь разрешил реализацию связки пешком → транспорт → пешком и публикацию после проверки. Существующий контракт матриц сохраняется.

1. Сохранить лицензированный снимок подмножества простых линий метро. Исключить ветвящиеся, устаревшие и неоднозначные линии; явно указать неполное покрытие.
2. Реализовать отдельный модуль: граф станций, ожидание при посадке/смене линии, пешие переходы между близкими станциями разных линий. Дейкстра от каждой точки, выбор между прямым пешим маршрутом и метро. Подходы по расстоянию с коэффициентом обхода — оценка, не проверенная тропа; вне покрытия явный fallback.
3. Встраивать результаты в public-матрицу при построении географии и добавлении адреса; хранить состав поездки и источник. Остальные виды транспорта не менять.
4. Показывать состав предыдущего переезда в карточке заявки. Геометрию метро не выдавать за дорожную трассу.
5. Тесты: пересадки, ожидание, короткий пеший путь, разрыв сети, отсутствие покрытия, валидность/детерминированность матриц, суммирование участков, применение в планировании. CI уже запускает все pytest; добавить проверку данных в wheel.
6. Пересчитать демо, проверить приложение и пакет, отдельно отправить main.

Ограничения: интервальная модель без времени суток, точных расписаний, реальных входов и закрытий. Исходный справочник неполон. Не выдавать это за полноценный навигатор Москвы и области.
