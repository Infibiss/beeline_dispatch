# YandexGPT Lite и уточнение норматива
Согласованный подход: объяснение рассчитанных вариантов, без права менять план, только обезличенные агрегаты; кэш и шаблон при сбое.
1. Проверить регрессии: сервис LLM не передаёт адреса/ID, кэширует ответ, ограничивает вызовы, корректно обрабатывает отказ; событие аварии по умолчанию 80 минут работы.
2. Добавить отдельный Yandex-клиент на стандартной библиотеке, конфигурацию .env без shell, endpoint объяснения вне блокировки состояния, кнопку внутри «Почему этот вариант». Не менять подписанный batch.
3. Обновить норматив в конфиге, форме, демо, документации. Норматив 100 = 20 дорога + 80 работа. Реальная модельная дорога отдельно, max(20,t) не вводим без подтверждения; 100 не делаем жёстким дедлайном. Пользовательская длительность остаётся длительностью работы.
4. Моки CI, один ограниченный живой вызов обезличенных показателей, проверка браузера, полный набор тестов, коммит и push main.

LLM выбирает 2–4 идентификатора проверенных тезисов; свободный текст от модели не отображается. Показатели и сравнения выводятся кодом из рассчитанных вариантов. Это ограничение введено после того, как Lite в живой проверке перепутала показатели стратегий. Невалидный формат ответа заменяется базовым пояснением.

## Результат проверки
Живое подключение YandexGPT работает. Первые свободные ответы путали время реакции и смысл стратегий; они не используются в итоговой реализации. Проверен формат JSON, в том числе блок кода, возврат к шаблону при свободном тексте/неизвестных тезисах, кэш, лимит вызовов, отсутствие частных полей в запросе, неизменность batch и возможность утверждения после объяснения.
В браузере: авария 11:50, адрес 35675, работа 80, роутер 1, сохранить начатое; расчёт и кнопка объяснения работают. Финальное пояснение корректно показало реакцию 243/243/212 минут и смену исполнителя 0/0/11 из текущего расчёта. План не утверждался.
Свежие утренние демо: Восток 66/66, Юго-восток 75/83, Югоцентр 55/56. Поиск 5 с, оптимальность не доказана.
Финальный scripts/check.sh: 202 passed, проверка JS и wheel успешны. CI запускает те же тесты без ключей и платных вызовов.
