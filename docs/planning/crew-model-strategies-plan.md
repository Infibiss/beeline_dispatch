# Бригады и стратегии — 22.09.2026

По запросу пользователя: сначала доработать модель бригад/стартов, затем уточнить экономическую стратегию. Рабочий день не заменяется экспериментом автоматически.

1. Разделить подготовку дня на независимые варианты относительно текущего состава: только домашние старты; только дополнительные навыки; только выдача под план с резервом; их сочетание. Число, ID, транспорт и смены существующих бригад сохраняются. Контрольный состав 12/12/11 — отдельная гипотеза.
2. Домашние точки выбирать среди известных адресов удалённых городов по матрицам, с учётом объёма работ, окон и доступных квалификаций. Это моделирование проживания, не реальные дома. Проверка итогового плана обязательна.
3. Дополнительные навыки предлагать только явно: для неназначенной работы с конструктивной возможностью вставки в существующий маршрут после добавления навыка. Не считать такие навыки подтверждёнными.
4. Предпросмотр показывает точный список изменений, приоритетный охват, время/километры дороги и бригады. Отдельное применение, версии и запрет изменения состава после начала дня сохраняются.
5. Сравнить варианты при одинаковом бюджете и утренней выдаче на трёх участках, валидировать планы. Отдельно проверить влияние резерва на возможность принять новую заявку; резерв не должен давать выдуманный выигрыш утреннего охвата.
6. Разобрать общую приоритетную часть и различия SLA / Stable / Cost. Предложение пользователю: во время дня Cost минимизирует время дороги, затем километры; численность — утренняя задача. Стоимость в рублях без тарифов не заявлять. Ответ ожидается параллельно работе над бригадами.

Проверки: изменения только выбранной оси; детерминированные предложения; известные точки и окна; не подменять регион/транспорт/смены; сохранение истории и фиксации оборудования; UI; полный scripts/check.sh. Коммиты по завершённым частям.
