# Подключение YandexGPT Lite — что подготовить

Проверено по документации 20.09.2026. В приложении LLM еще не подключена; эти настройки предназначены для следующего этапа.

1. Каталог Yandex Cloud/AI Studio с доступным биллингом, его folder ID.
2. Сервисный аккаунт с ролью `ai.languageModels.user` и API-ключ для Responses API с областью `yc.ai.foundationModels.execute`.
3. Сохранить локально, например в игнорируемом `.env`: `YANDEX_FOLDER_ID`, `YANDEX_API_KEY`. Не присылать ключ в переписке, не коммитить.
4. Выбранная модель: `gpt://<folder_id>/yandexgpt-5-lite` по актуальному каталогу моделей. Endpoint Responses API: `https://ai.api.cloud.yandex.net/v1/responses`.
5. На старте ограничить выход 500 токенами, кэшировать объяснение по версии плана/кандидату. Отправлять только обезличенные рассчитанные показатели/причины, без адресов и координат. Модель не меняет назначения и не утверждает план. При сбое остаётся детерминированное объяснение.

Тариф YandexGPT Lite на момент проверки: 0.20 ₽ / 1000 входящих и 0.20 ₽ / 1000 исходящих токенов, с НДС. 2000 входящих + 500 исходящих ≈ 0.50 ₽ за объяснение без дополнительных услуг. Нужен выбранный пользователем лимит расходов для тестовых вызовов.
